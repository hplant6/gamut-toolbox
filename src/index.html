Move Tool
Select an element, then drag it to where it should go.

Click an element to select it, then drag from anywhere to where it should go.

  • With something selected, a click selects something else. Only a drag moves.
  • Shift+click to select several and move them together
  • The Snap | Drag switch under your selection picks how it lands: snapped into the layout, or anywhere you point (S flips it)
  • Hold Shift while dragging to snap to the parent
  • Hold Ctrl on release to nudge by pixels instead
  • Click an arrow's number or arrowhead to delete it, or Ctrl+Z to undo the last one
